PROJECT NOTES / OCTOBER 2026

How the projects work.

Design decisions, failure cases, and repeatable validation. Measurements below are local synthetic tests, not production usage or real-world accuracy claims.

WorkLikeADog

Job → eligibility rules → duplicate check → review → application record

The workflow keeps application state in SQLite and pauses interrupted work for review after restart. Eligibility uses the candidate’s graduation year and distinguishes unknown answers from clear rejection. Duplicate checks use indexed URLs and normalized company/title fields, avoiding loading every active application.

Evidence: 72 local tests passed; one LaTeX-dependent test skipped locally. A 17-case labeled synthetic eligibility fixture and six skill-boundary cases pass. On this Mac, duplicate-check p95 stayed below 0.7 ms at both 1,000 and 10,000 synthetic records.

Tradeoff: rules need evaluation on new, independently labeled job postings. Matching “Java” inside “JavaScript” is now a regression case; the small fixture does not establish real-world eligibility accuracy.

CyberSteer

Webcam landmarks / keys / touch → lane input → fixed-step simulation → Canvas

MediaPipe supplies landmarks; the game validates them, mirrors the palm coordinate, and applies lane hysteresis. Keyboard and touch work independently of camera availability. A fixed 60 Hz update step preserves gameplay pacing across 30, 60, and 120 Hz rendering.

Evidence: regression checks cover nine viewport sizes, rotation, pause/restart, collisions, keyboard input, unavailable camera/CDN/storage, and synthetic landmark jitter.

Tradeoff: emulation and synthetic landmarks do not measure physical camera recognition, camera-to-control latency, or actual iOS/Android performance. The repository includes a device-check protocol.

Music Player

Catalog / imports → IndexedDB + playback queue → bounded library UI → native audio

Imported audio stays in the browser’s IndexedDB. The app shell supports offline reload after an online visit; live radio still needs a connection. Library and queue lists render 100 rows per page, and the disc carousel renders 24 records at a time while keeping every track reachable.

Evidence: one local Chromium comparison at 1,000 synthetic tracks reduced the DOM from 132,217 to 5,900 elements. The 10,000-track fixture also rendered 5,900 elements and successfully searched and played the last track. Tests cover imported-audio playback after an offline reload.

Tradeoff: metadata remains in memory, browser storage quotas apply, and the benchmark does not import 10,000 audio files. Local timings are illustrative, not a promise for every device.

JWT authentication + RBAC

Credential check → signed access token + session → role / ownership check → API

SHA-256 hashes protect stored bearer-token identifiers. Refresh rotation uses an atomic conditional database update. Access checks verify the live session, so logout and password changes revoke access immediately. SQL-backed tests exercise replay, concurrent refresh, expired tokens, roles, ownership, and one-time password reset.

Tradeoff: browser bearer tokens retain XSS exposure. Persistent fixed-window rate limiting is simple but allows bursts across window boundaries. The security update is not an independent security audit, and rollout requires a database migration and fresh sign-in for legacy sessions.

03 / INTERACTIVEHTML

CyberSteer.

A browser racing game controlled with real-time hand tracking or your keyboard.

Inside the build +
THE INPUT
MediaPipe palm coordinates mapped to mirrored steering zones, with hysteresis to stabilize lane changes.
THE ENGINE
HTML5 Canvas rendering, procedural traffic, AABB collision detection, and speed progression.
THE EXPERIENCE
Hand and keyboard control options, smooth steering, and persistent high scores.

SwopMobile.

A serverless workspace with role-based permissions and rotating authentication tokens.

Inside the build +

A serverless workspace built with Cloudflare Workers, Hono, and D1.

Three permission roles, PBKDF2-SHA256 password hashing, JWT session checks, atomic token rotation, and live-session revocation.

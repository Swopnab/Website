FASTAPI · SQLITE · OLLAMA

WorkLikeADog.

A local job-search companion for organizing opportunities, matching verified experience, and preparing résumés for human review.

Public demo: fictional jobs and browser storage. Full AI and document workflows run locally.

Inside the build +
THE GOAL
Bring job research, application tracking, and résumé preparation into one workspace.
THE APPROACH
FastAPI and SQLAlchemy with indexed SQLite persistence, optional local Ollama analysis, Playwright preparation, and recoverable application workflows.
THE DESIGN CHOICE
Keep candidate data local and leave final application review and submission with the user.

01

CYBERSTEER

Computer vision / Browser game

Steer through highway traffic with your hand or keyboard. Real-time MediaPipe tracking meets a fast-paced Canvas racing game.

  • JAVASCRIPT
  • MEDIAPIPE
  • CANVAS
Inside the build +
THE INPUT
MediaPipe palm coordinates mapped to mirrored steering zones, with hysteresis to stabilize lane changes.
THE ENGINE
HTML5 Canvas rendering, procedural traffic, AABB collision detection, and speed progression.
THE EXPERIENCE
Hand and keyboard control options, smooth steering, and persistent high scores.

EXPLORE THE PLATFORM ↗
02

SWOPMOBILE

Authentication / Full-stack platform

A serverless workspace built around secure sign-in, three permission roles, rotating refresh tokens, and isolated user data.

  • CLOUDFLARE
  • HONO / D1
  • JWT / RBAC
Inside the build +
THE PLATFORM
A serverless workspace built with Cloudflare Workers, Hono, and D1.
THE SECURITY
Three permission roles, PBKDF2-SHA256 password hashing, JWT session checks, atomic token rotation, and live-session revocation.
THE BOUNDARY
Protected routes and server-side permissions isolate each user’s data.
